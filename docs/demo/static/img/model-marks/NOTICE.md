# Model provider marks

The SVG files in this directory are copied unmodified from the npm package
`@lobehub/icons-static-svg` 1.95.0 (https://github.com/lobehub/lobe-icons),
MIT License, Copyright (c) LobeHub. They are the single-colour variants
(`fill="currentColor"`), so each takes the colour of the text around it.
CodeNotch (https://github.com/vinzdg/codenotch) uses the same set for its
Claude and Codex rings, which is where this choice comes from.

Which mark an added model gets is decided in `core/model_marks.py`.

**Trademarks:** each mark is a trademark of its owner (Anthropic, OpenAI, xAI,
Google, Perplexity, DeepSeek, Mistral AI, Meta, Alibaba (Qwen), Microsoft,
Cohere, Moonshot AI (Kimi), Zhipu AI, MiniMax, NVIDIA, OpenRouter, Groq,
Together AI, Fireworks AI, Hugging Face, Ollama, LM Studio). They are shown only
to identify which provider's model a row refers to. Whether they stay in a
distributed build is the repository owner's call under each brand's guidelines.
