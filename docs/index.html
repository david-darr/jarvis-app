CONVERSATION

Follow the thought.

A calm reading column and a softly animated composer. Add a file, bring in a reference, or change models as your work evolves.

Collapse the sidebar when you want more space. Your next destination is still one icon away.

KNOWLEDGE

See how ideas connect.

Your vault becomes a constellation of notes and folders. Search for a thought, explore its neighbors, or browse the files directly.

Your memory is still plain Markdown. The view is simply another way into it.

AUTOMATIONS

Give your day a head start.

A morning brief. A review of your priorities. A prompt you want to run every week. Set the schedule, then see what happened.

Real run history and delivery status, alongside the controls that matter.

YOUR SETUP

Bring what works for you.

Connect Claude or Codex, a local model server, or an OpenAI-compatible provider. Pick the model inside each conversation.

No model is included by default. Provider accounts, usage, and hardware requirements are yours to choose.

Make yourself at home

Your workspace starts here.

The desktop app includes its Python runtime.
No separate Python installation needed.

  1. Install JARVIS

    Choose Windows or macOS on Apple Silicon from the latest release.

  2. Choose your vault

    Start fresh or point JARVIS at the Markdown knowledge you already keep.

  3. Connect a model

    Add your preferred model in Settings, then start a conversation.

Before you install

Builds are not code-signed yet. Windows SmartScreen and macOS Gatekeeper may require you to approve the app. The macOS build supports Apple Silicon, not Intel Macs. Screenshots show the development UI with demo data; the latest packaged release may differ.

The workspace runs locally. When you choose a cloud model or connect an external service, relevant data is sent to that provider.
